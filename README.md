# ATSlibrary
在香港仔工業學校的圖書館找彩蛋，彩蛋位置隨機，範圍包含圖書館和階梯教室.
本游戲使用UE5製作，素材來源網上搜索、學校官網、谷歌街景地圖等

## Windows 版

在 [Releases](https://github.com/cyrus-promax/ATSlibrary/releases) 下載 `ATS-Library-Hunt-Windows.zip`，解壓縮全部檔案後開啟 `ATS.exe`。

## Unreal Engine 專案

安裝 Git LFS，複製儲存庫後執行 `git lfs pull` 下載素材，再以 Unreal Engine 5.8 開啟 `ATS.uproject`。素材出處見[資料來源與版權](資料來源與版權.txt)。
